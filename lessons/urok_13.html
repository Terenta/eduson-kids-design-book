НОВАЯ ИДЕЯ

База данных хранит записи между запусками

  • База данных — организованное хранилище записей, которыми работает приложение.
  • Каждая запись содержит свойства объекта. Для игры это название, студия, жанр, оценка и статус.
  • Программа добавляет, читает, изменяет и удаляет записи по действиям пользователя.
  • После нового запуска программа читает сохранённые записи и передаёт их интерфейсу.
Проверка постоянного хранения: полностью остановить программу, запустить её снова и увидеть прежние записи.

СРАВНИВАЕМ ОПЫТ ПОЛЬЗОВАТЕЛЯ

Один и тот же сайт — два разных опыта

Без постоянной памяти

  • Карточка появилась на экране
  • Пользователь закрыл программу
  • При новом запуске каталог пуст
  • Поиск и статусы нечего обрабатывать

С базой данных

  • Карточка появилась на экране и записалась в файл
  • Программу можно полностью закрыть
  • После нового запуска карточка возвращается
  • Поиск, фильтры и счётчики работают со всей коллекцией
База данных сохраняет историю изменений: новые записи, обновлённые статусы и удалённые элементы учитываются при следующем запуске.
ВЫБОР ПО МАСШТАБУ

Хранилище выбирают по задаче

Память браузера

Когда: Один браузер, мало данных

+ Можно обойтись без Python-сервера

− Данные привязаны к одному браузеру; сложнее сделать копию

НАШ ВЫБОР

SQLite в файле

Когда: Один пользователь или небольшая локальная программа

+ Не нужен аккаунт и отдельный сервер; данные находятся в games.db

− Не подходит для большого числа одновременных операций записи

Облачная база

Когда: Публичный сайт и много пользователей

+ Общие данные доступны с разных устройств; можно расти

− Нужны аккаунт, интернет, настройка доступа, резервные копии и контроль расходов

SQLite подходит для локального проекта: данные сохраняются в одном файле, а отдельный сервер базы устанавливать не требуется.

Python not found
На компьютере не найден Python из урока 1. Позовите преподавателя; не скачивайте случайный «Python» с неизвестного сайта.
Браузер не открылся сам
В чёрном окне найдите строку «Приложение работает» и откройте указанный localhost-адрес вручную.
После правки белая страница
Верните копию index.html. Затем отправьте DeepSeek точный текст из DevTools и попросите исправить только эту ошибку.
Не удаляйте games.db при ошибке интерфейса: это удалит сохранённые данные и не исправит причину сбоя.
